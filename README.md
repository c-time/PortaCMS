# 製品概要書: PortaCMS

## 1. 製品名

PortaCMS (ポルタCMS)

## 2. 製品カテゴリ

ローカルファイルベース・ヘッドレスCMS
（クラウドストレージ対応）

## 3. 製品概要 (エレベーターピッチ)

PortaCMSは、ウェブサイト制作業者のモダンな開発ワークフロー（Git管理、SSG利用）に最適化されたヘッドレスCMSです。コンテンツと設定は**ローカルファイル（デフォルト）またはクラウドストレージで管理**でき、データベースが不要で、環境構築や設定の再利用が容易です。**さらに、入力用データモデルとページ表示用データをマッピングするデータ変換機能により、SSG側のロケを最小限に抑えます。**

## 4. ターゲットユーザー

* 静的サイトジェネレーター（SSG: Next.js, Astro, Eleventyなど）を利用するウェブサイト制作者・開発チーム。

* Gitベースでのコンテンツ管理を行いたい開発者。

* 管理画面はウェブでホスティングしつつ、データはファイルベースで管理したいチーム。

## 5. 主要な特徴とアーキテクチャ

### 特徴1: ファイルベース管理 & 柔軟なホスティング

* **柔軟なホスティング:** CMSはローカル環境（開発者のPC）での動作を基本としますが、管理画面をウェブサーバーにホストすることも可能です。

* **DB不要:** コンテンツや設定はすべてファイル（JSON、Markdownなど）として保存されます。

* **Git親和性:** （ローカルファイル利用時）コンテンツの変更履歴管理やブランチ運用など、Gitのワークフローにそのまま組み込めます。

### 特徴2: データ変換機能 (SSG連携の最適化)

* **SSG連携特化:** 本製品はコンテンツ管理機能のみを提供し、ビュー（ウェブサイトのフロントエンド）は提供しません。

* **データトランスフォーマー:** 入力用のコンテンツモデル（例: "製品"）と、SSGがページ生成に使うデータ構造（例: "製品一覧ページ用JSON"）の差を、CMS側で吸収するデータ変換機能を持ちます。

* **SSGの責務軽減:** この機能により、SSG側は複雑なデータ加工ロジックを持つ必要がなくなり、受け取ったJSONをHTMLにバインドするシンプルなテンプレートエンジンとして機能します。

* **データソース:** SSGがビルド時に直接参照できる、最適化されたデータソース（ファイル群）を生成・管理します。

### 特徴3: 高いカスタマイズ性と再利用性 (開発者向け)

* **カスタムスキーマ:** サイト制作者は、コンテンツの入力インターフェース（管理画面）をJSONスキーマで自由に定義できます。「お知らせ」「製品情報」など、プロジェクト固有のコンテンツ構造を柔軟に作成可能です。

* **JSONによる設定管理:** CMS全体のプロジェクト設定もすべてJSONファイルで管理されます。これにより、設定のバックアップ、複製、別プロジェクトへの流用が容易になり、制作効率が向上します。

### 特徴4: プラガブル・ストレージ (拡張性)

* **デフォルトはローカルファイル:** コンテンツと設定は、標準でローカルファイルシステムに保存されます。

* **クラウドストレージ対応:** ストレージ層を切り替える（プラガブルな）アーキテクチャを採用。管理画面をウェブホスティングする際は、Amazon S3やGoogle Cloud Storageなどのオブジェクトストレージをデータ保存先として指定可能です。

### 特徴5: プラガブル認証 (拡張性)

* **柔軟な認証メカニズム:** 認証層もプラガブルであり、プロジェクトのセキュリティ要件に合わせて選択可能です。

* **サポートオプション:**

  * 静的なID/パスワード管理（簡易認証）

  * Firebase Authentication

  * AWS Cognito

  * （その他、アダプタ経由で拡張可能）

## 6. 提供しないもの (スコープ外)

* 静的サイトジェネレーター (SSG) 機能そのもの

* ウェブサーバー / ホスティング機能（※管理画面のホスティング環境はユーザーが用意）

* データベース管理機能
